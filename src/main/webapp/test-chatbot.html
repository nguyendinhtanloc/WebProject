🤖 Test Chatbot Gemini AI

📝 Lưu ý quan trọng:

  • Đảm bảo đã cấu hình GEMINI_API_KEY trong ChatbotServlet.java
  • Server phải đang chạy (Tomcat/Jetty)
  • Endpoint /api/chatbot phải hoạt động

🚀 Cách test:

  1. Click vào biểu tượng chat ở góc phải màn hình
  2. Thử các câu hỏi mẫu:
    • "Cách đặt vé xe buýt như thế nào?"
    • "Giá vé từ Hà Nội đi TP.HCM?"
    • "Tôi có thể hủy vé không?"
    • "Các phương thức thanh toán nào được hỗ trợ?"
  3. Kiểm tra response time và chất lượng câu trả lời
  4. Test trên mobile device

⚠️ Troubleshooting:

  • Chatbot không hiện: Kiểm tra console errors
  • API lỗi 404: Kiểm tra servlet mapping
  • API lỗi 500: Kiểm tra Gemini API key
  • CORS errors: Kiểm tra headers trong servlet
